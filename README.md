# 🍽 Smart Canteen Management System

A web-based canteen management system developed using PHP and MySQL to simplify food ordering and management within a college or organization.

---

## 🚀 Features

* 👤 User registration and login
* 🍔 View available food items
* 🛒 Place food orders
* 📦 Manage orders
* 🛠 Admin functionalities (add/update/delete items)

---

## 🛠 Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: PHP
* Database: MySQL
* Server: XAMPP

---

## 📂 Project Overview

This project helps digitize the traditional canteen system by allowing users to browse menu items and place orders online. It also provides basic admin functionalities to manage food items and orders efficiently.

---

## ⚙️ Setup Instructions

1. Install XAMPP
2. Move the project folder to:

   ```
   D:/xampp/htdocs/
   ```
3. Start **Apache** and **MySQL** in XAMPP
4. Import the database into **phpMyAdmin**
5. Open your browser and run:

   ```
   http://localhost/SmartCanteen
   ```

---

## ⚠️ Important Notes

* Database configuration is stored in `db_connection.php`
* Make sure to update database credentials before running
* Sensitive files are excluded using `.gitignore`
